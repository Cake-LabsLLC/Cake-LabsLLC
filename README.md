This is the GitHub page of Cake Wallet Desktop, a wallet for Monero (XMR) on Windows, macOS and Linux. It is also a home for people moving from the MyMonero desktop wallet: you can restore your MyMonero seed in Cake Wallet and keep using the same funds.
